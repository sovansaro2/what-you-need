# Shared Application UI Components

This directory contains reusable, accessible UI primitives adhering to project standards:

- **Button**: Touch-friendly button (min height 44px/48px) with state/variant styling.
- **Input**: Accessible form text input with label, icon support, and error state.
- **Card**: Standard rounded-2xl container with shadow and hover micro-interactions.
- **Modal**: Accessible modal dialog with backdrop blur and header structure.
- **Badge**: Status/Category tag chips with semantic colors.

## Standards

- Khmer-first typography (Khmer OS Battambang)
- No emojis (Lucide React icons only)
- Minimum 44px touch targets on mobile
